# Market Trend Analyzer

## Project Overview
This is a personal research tool designed to analyze market trends by aggregating public data from niche business subreddits (e.g., r/SaaS, r/marketing).

## Technical Implementation
- **Language:** Python 3.10+
- **Library:** PRAW (Python Reddit API Wrapper)
- **Functionality:** - Read-only access to public subreddit feeds.
  - Keyword filtering to identify relevant industry discussions.
  - Local database storage for personal review.

## Policy Compliance
This tool adheres to Reddit's API terms:
- No automated posting or spamming.
- Respects rate limits (60 requests/min).
- No scraping of private user data.
